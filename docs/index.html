Lindows

Lightweight Linux commands for Windows — built so AI coding agents and developers never trip over missing Unix utilities again.

One-Command Install (Lindows + uutils.coreutils + ripgrep)
irm https://raw.githubusercontent.com/lochgeo/lindows/main/install.ps1 | iex

Why Lindows?

When running AI coding agents on Windows (such as Claude Code, OpenCode, Cursor, Codex, etc.), almost all of them naturally assume they are operating in a Linux or macOS environment.

They reflexively run commands like grep -rn, find . -name "*.ts", head -n 20, tail -n 50, wc -l, rm -rf, mkdir -p, or lsof -i :3000 — and either fail or waste turns when those commands aren't found or collide with incompatible Windows built-ins (FIND.EXE, PowerShell's rm / mkdir / cat aliases).

Lindows is a lightweight, modular shim project that fills that gap across both PowerShell and cmd.exe.

Commands Included

Command Module File Supported Flags & Capabilities
grep src/grep.ps1 Search files or piped input (-i, -v, -n, -c, -l, -L, -o, -r, -F, -E, -w, -x, -A/-B/-C, --include, --exclude)
find src/find.ps1 Search directory trees without hitting Windows FIND.EXE (-name, -iname, -path, -type f|d, -maxdepth, -mindepth, -not/!, -empty, -delete)
head src/head.ps1 Output the first part of files or piped input (-n NUM, -n -NUM, -c BYTES, -q, -v)
tail src/tail.ps1 Output the last part of files or piped input (-n NUM, -n +NUM, -c BYTES, -f, -q, -v)
wc src/wc.ps1 Count lines, words, characters, and bytes (-l, -w, -c, -m)
touch src/touch.ps1 Create empty files or update timestamps (-c, -a, -m)
cat src/fs.ps1 Concatenate and print files with Unix flags (-n, -b, -s, -E)
rm src/fs.ps1 Remove files and directories with Unix flags (rm -rf, rm -r, rm -f, rm -v)
mkdir src/fs.ps1 Create directories with Unix flags (mkdir -p, mkdir -v)
lsof src/proc.ps1 Inspect active network ports and owning PIDs (lsof -i :3000, lsof -t -i :3000, lsof -p PID)
pkill / killall src/proc.ps1 Find or stop processes by name or command line (pkill -f, pkill -l, pkill -c)
which src/which.ps1 Locate executables on Windows PATH (-a, -i for PowerShell aliases)
tree src/tree.ps1 Recursive directory tree viewer (-a, -d, -L, -P, -I, --dirsfirst, -h, -s, -D)
man src/man.ps1 Embedded manual pages (-f, -k, -w) and PowerShell pointers
clear src/meta.ps1 Clear terminal screen in CMD and PowerShell
lindows src/meta.ps1 Meta CLI (lindows list, lindows doctor, lindows --version)

Pairing with uutils.coreutils & ripgrep

By default, install.ps1 also ensures uutils.coreutils and ripgrep are installed via winget so your Windows machine has the complete GNU/Linux toolset: 

winget install uutils.coreutils
winget install BurntSushi.ripgrep.MSVC

If you only want the Lindows PowerShell/CMD shims without running winget, pass -SkipExtras to .\install.ps1.
