NAME
tail — output the last part of files or piped input
SYNOPSIS
tail [-n [+]NUM] [-c [+]NUM] [-f] [-q] [-v] [FILE]...
DESCRIPTION
Print the last 10 lines of each FILE to standard output. With more than one FILE, precede each with a header giving the file name. With no FILE, or when FILE is -, read standard input or PowerShell pipeline objects.
SUPPORTED FLAGS & OPTIONS
-n [+]NUM, --lines=[+]NUM, -NUM
Output the last NUM lines instead of the last 10; or use -n +NUM to output starting with line NUM (1-indexed).
-c [+]NUM, --bytes=[+]NUM
Output the last NUM bytes; or use -c +NUM to output starting with byte NUM.
-f, -F, --follow
Output appended data as the file grows in real time.
-q, --quiet, --silent
Never output headers giving file names.
-v, --verbose
Always output headers giving file names.
-h, --help
Display help message and exit.
--version
Output version information and exit.
EXAMPLES
tail -n 25 server.log
# Print the last 25 lines of server.log
tail -n +2 data.csv
# Print all lines starting from line 2 (skipping CSV header)
tail -f app.log
# Follow new log lines as they are written
