NAME
wc — print newline, word, character, and byte counts for each file
SYNOPSIS
wc [-l] [-w] [-c] [-m] [FILE]...
DESCRIPTION
Print newline, word, and byte counts for each FILE, and a total line if more than one FILE is specified. With no FILE, or when FILE is -, read standard input or PowerShell pipeline objects.
SUPPORTED FLAGS & OPTIONS
-l, --lines
Print the newline (line) counts.
-w, --words
Print the whitespace-delimited word counts.
-c, --bytes
Print the byte counts.
-m, --chars
Print the character counts.
--help, --version
Display help or version information and exit.
EXAMPLES
wc -l Lindows.psm1
# Count lines in a file
find src -name "*.ps1" | wc -l
# Count how many .ps1 files are in src/
