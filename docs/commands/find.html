NAME
find — search for files and directories in a directory hierarchy
SYNOPSIS
find [PATH...] [EXPRESSION]
DESCRIPTION
find recursively walks the directory tree rooted at each given PATH (defaulting to .) and evaluates the given expression. Replaces the legacy Windows C:\Windows\System32\find.exe string-finder so Unix find expressions work natively.
SUPPORTED FLAGS & OPTIONS
-name PATTERN
Base of file name matches shell wildcard PATTERN (case-sensitive, e.g. "*.ps1").
-iname PATTERN
Like -name, but the match is case-insensitive.
-path PATTERN, -wholename PATTERN
Full relative path matches shell wildcard PATTERN.
-type f | d
Filter by entry type: f for regular files, d for directories.
-maxdepth LEVELS
Descend at most LEVELS (a non-negative integer) levels of directories below the starting points.
-mindepth LEVELS
Do not apply any tests or actions at levels less than LEVELS.
-empty
File is empty (0 bytes) or directory contains no entries.
! , -not
Negate the following -name, -iname, or -path pattern (also prunes matching directories).
-delete
Delete matched files or directories.
-print
Print the full file name on standard output (default action).
EXAMPLES
find . -name "*.ps1" -type f
# Find all PowerShell files under current directory
find src -maxdepth 1 -type f
# List files directly inside src/ without descending further
find . -not -path "*/.git/*" -type f
# Find all files excluding .git directory
