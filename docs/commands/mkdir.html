NAME
mkdir — make directories
SYNOPSIS
mkdir [-p] [-v] [-m MODE] DIRECTORY...
DESCRIPTION
Create the DIRECTORY(ies), if they do not already exist. Replaces PowerShell's default mkdir function where passing -p fails with an ambiguous parameter error.
SUPPORTED FLAGS & OPTIONS
-p, --parents
No error if existing, make parent directories as needed.
-v, --verbose
Print a message for each created directory.
-m MODE, --mode=MODE
Accepted for POSIX compatibility (no-op on Windows).
--help, --version
Display help or version information and exit.
EXAMPLES
mkdir -p src/components/ui
