NAME
head — output the first part of files or piped input
SYNOPSIS
head [-n [-]NUM] [-c [-]NUM] [-q] [-v] [FILE]...
DESCRIPTION
Print the first 10 lines of each FILE to standard output. With more than one FILE, precede each with a header giving the file name. With no FILE, or when FILE is -, read standard input or PowerShell pipeline objects.
SUPPORTED FLAGS & OPTIONS
-n [-]NUM, --lines=[-]NUM, -NUM
Print the first NUM lines instead of the first 10; with a leading -, print all but the last NUM lines of each file.
-c [-]NUM, --bytes=[-]NUM
Print the first NUM bytes of each file; with a leading -, print all but the last NUM bytes.
-q, --quiet, --silent
Never print headers giving file names.
-v, --verbose
Always print headers giving file names.
-h, --help
Display help message and exit.
--version
Output version information and exit.
EXAMPLES
head -n 20 README.md
# Print the first 20 lines of README.md
head -n -5 data.txt
# Print all lines except the last 5 lines
git log --oneline | head -n 5
# Take the first 5 lines from a pipeline
