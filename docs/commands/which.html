NAME
which — locate a command on the Windows PATH
SYNOPSIS
which [-a] [-i] [--skip-alias] [--help] [--version] NAME...
DESCRIPTION
Prints the full path of the executable(s) that would be executed in the current environment for each NAME. Automatically checks Windows executable extensions (.exe, .cmd, .bat, .ps1, .com).
SUPPORTED FLAGS & OPTIONS
-a, --all
Print all matching executables in PATH order, not just the first.
-i, --read-alias
Also resolve and display PowerShell aliases matching NAME.
--skip-alias
Ignore aliases even if -i was specified.
-h, --help, --version
Display help or version information and exit.
EXAMPLES
which git node
# Locate git and node executables on PATH
which -a python
# List all python executables across PATH
