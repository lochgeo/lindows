NAME
lindows — meta command for inspecting and verifying Lindows
SYNOPSIS
lindows [list | doctor | --help | --version]
DESCRIPTION
Meta CLI utility for listing all commands provided by Lindows and checking installation health (%LOCALAPPDATA%\lindows, User PATH shims, and PowerShell profile hook).
SUBCOMMANDS & OPTIONS
list
List all commands provided by Lindows with a short description of each.
doctor
Verify that the Lindows module, CMD shims on User PATH, and PowerShell $PROFILE hook are properly configured.
--version
Print the installed Lindows version.
--help
Print usage instructions.
EXAMPLES
lindows list
# List all available Lindows commands
lindows doctor
# Run installation health checks
