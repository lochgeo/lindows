MAN(1) Lindows Manual Pages MAN(1)
NAME
man — display manual pages for Lindows commands and Windows equivalents
SYNOPSIS
man [-f] [-k] [-w] [-d] [-l FILE] NAME...
DESCRIPTION
Displays embedded manual pages for all Lindows commands, or provides the PowerShell / Microsoft.Coreutils equivalent for other Unix commands.
SUPPORTED FLAGS & OPTIONS
-f, --whatis
Display a one-line summary from the manual page if available.
-k, --apropos
Search all embedded manual pages for keyword and print summaries.
-w, --where, --path
Show whether the manual page exists rather than displaying it.
-l FILE, --local FILE
Display a local file as a manual page.
-h, --help, --version
Display help or version information and exit.
EXAMPLES
man grep
# View the full manual page for grep
man -f head
# Print a one-line summary for head
man -k port
# Search manual pages mentioning "port"
