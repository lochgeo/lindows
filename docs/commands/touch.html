NAME
touch — change file timestamps or create empty files
SYNOPSIS
touch [-c] [-a] [-m] FILE...
DESCRIPTION
Update the access and modification times of each FILE to the current time. A FILE argument that does not exist is created empty (0 bytes, UTF-8 without BOM), unless -c is supplied.
SUPPORTED FLAGS & OPTIONS
-c, --no-create
Do not create any files if they do not already exist.
-a
Change the access time.
-m
Change the modification time.
--help, --version
Display help or version information and exit.
EXAMPLES
touch .nojekyll
# Create an empty .nojekyll file
touch a.txt b.txt c.txt
# Create or update timestamps on multiple files
