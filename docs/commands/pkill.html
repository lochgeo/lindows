PKILL(1) Lindows Manual Pages PKILL(1)
NAME
pkill, killall — look up or terminate processes by name or command line
SYNOPSIS
pkill [-f] [-i] [-x] [-l] [-c] [-9] PATTERN
killall [OPTIONS] PATTERN
DESCRIPTION
Finds and terminates running Windows processes matching PATTERN. Both pkill and killall are exported and shimmed. Never kills the current PowerShell process ($PID).
SUPPORTED FLAGS & OPTIONS
-f, --full
Match PATTERN against the full process command line (via WMI/CIM Win32_Process), not just the executable name.
-i, --ignore-case
Match case-insensitively.
-x, --exact
Require an exact match of the process name.
-l, --list-name
List matching process IDs and process names without terminating them.
-c, --count
Print a count of matching processes without terminating them.
-9, -15, -KILL, -TERM
Accepted for POSIX signal flag compatibility.
EXAMPLES
pkill -f "vite"
# Stop any background node process running vite
pkill -l node
# List matching node processes and PIDs without killing them
