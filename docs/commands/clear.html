NAME
clear — clear the terminal screen
SYNOPSIS
clear
DESCRIPTION
Clears the terminal screen. In cmd.exe, Lindows provides a clear.cmd shim that calls cls. In PowerShell, Invoke-LindowsClear / Clear-Host clears the console host.
