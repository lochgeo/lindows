NAME
cat — concatenate files and print on the standard output
SYNOPSIS
cat [-n] [-b] [-s] [-E] [FILE]...
DESCRIPTION
Concatenate FILE(s) to standard output. Replaces PowerShell's built-in cat alias (Get-Content) so Unix flags like cat -n and multi-file concatenation work without parameter binding errors.
SUPPORTED FLAGS & OPTIONS
-n, --number
Number all output lines starting at 1.
-b, --number-nonblank
Number nonempty output lines, overrides -n.
-s, --squeeze-blank
Suppress repeated empty output lines.
-E, -e, -A, --show-ends
Display $ at the end of each line.
--help, --version
Display help or version information and exit.
EXAMPLES
cat -n Lindows.psm1
# Print file contents with 1-based line numbers
cat part1.txt part2.txt
# Concatenate multiple files to stdout
