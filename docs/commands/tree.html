TREE(1) Lindows Manual Pages TREE(1)
NAME
tree — list contents of directories in a tree-like format
SYNOPSIS
tree [-adFfistrhD] [-L level] [-P pattern] [-I pattern] [-o file] [--dirsfirst] [--charset=ascii|utf8] [DIR...]
DESCRIPTION
Recursive directory listing program that produces a depth-indented listing of files. Unlike Windows' built-in tree.com, Lindows tree supports Unix flags like -L (max depth), -I (ignore pattern), -a (hidden files), and file sizes.
SUPPORTED FLAGS & OPTIONS
-a
Include hidden and dot-prefixed files.
-d
List directories only.
-L level
Max display depth of the directory tree.
-P pattern
List only those files that match the wild-card pattern.
-I pattern
Do not list those files or directories that match the wild-card pattern.
--dirsfirst
List directories before files.
-f
Print the full path prefix for each file.
-F
Append / for directories and * for executable files.
-i
Makes tree not print the indentation lines.
-s
Print the size of each file in bytes.
-h
Print the size of each file in a human-readable way (K, M, G).
-D
Print the date of the last modification time.
-t
Sort the output by last modification time instead of alphabetically.
-r
Sort the output in reverse order.
-o FILE
Send output to FILE.
--charset=ascii|utf8
Select line drawing characters (defaults to utf8).
EXAMPLES
tree -L 2 -I "node_modules"
# Show 2 levels deep, ignoring node_modules
tree --dirsfirst -s -h src
# Show src/ with human-readable sizes and directories first
