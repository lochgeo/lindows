NAME
grep — print lines that match patterns in files or standard input
SYNOPSIS
grep [OPTION]... PATTERNS [FILE]...
grep [OPTION]... -e PATTERNS ... [FILE]...
DESCRIPTION
grep searches for PATTERNS in each FILE (or piped/redirected standard input when no file or - is given) and prints each line that matches. Implemented in src/grep.ps1 using .NET regular expressions.
SUPPORTED FLAGS & OPTIONS
-E, --extended-regexp
Interpret PATTERNS as extended regular expressions (default in Lindows).
-F, --fixed-strings
Interpret PATTERNS as fixed literal strings instead of regular expressions.
-i, --ignore-case
Ignore case distinctions in patterns and input data.
-v, --invert-match
Invert the sense of matching, to select non-matching lines.
-w, --word-regexp
Select only those lines containing matches that form whole words.
-x, --line-regexp
Select only those matches that exactly match the whole line.
-n, --line-number
Prefix each line of output with the 1-based line number within its input file.
-c, --count
Suppress normal output; instead print a count of matching lines for each input file.
-l, --files-with-matches
Suppress normal output; instead print the name of each input file from which output would normally have been printed.
-L, --files-without-match
Suppress normal output; instead print the name of each input file from which no output would normally have been printed.
-o, --only-matching
Print only the matched (non-empty) parts of a matching line, with each such part on a separate output line.
-r, -R, --recursive
Read all files under each directory, recursively.
-H, --with-filename
Print the file name for each match (default when there is more than one file or -r).
-h, --no-filename
Suppress the prefixing of file names on output.
-q, --quiet, --silent
Quiet; do not write anything to standard output. Exit immediately with zero status if any match is found.
-s, --no-messages
Suppress error messages about nonexistent or unreadable files.
-e PATTERN, --regexp=PATTERN
Use PATTERN as the pattern; can be specified multiple times to match any of the given patterns.
-m NUM, --max-count=NUM
Stop reading a file after NUM matching lines.
-A NUM, --after-context=NUM
Print NUM lines of trailing context after matching lines.
-B NUM, --before-context=NUM
Print NUM lines of leading context before matching lines.
-C NUM, -NUM, --context=NUM
Print NUM lines of leading and trailing output context.
--include=GLOB
Search only files whose base name matches GLOB when recursing.
--exclude=GLOB
Skip any file whose base name matches GLOB when recursing.
--exclude-dir=DIR
Skip any directory matching DIR when recursing (e.g. node_modules, .git).
EXAMPLES
grep -rn "Invoke-Lindows" src/
# Search recursively with line numbers
grep -i -C 2 "error" app.log
# Case-insensitive search with 2 lines of context
git status -s | grep -v "README"
# Filter piped output using inverted match
